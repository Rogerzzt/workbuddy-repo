## 一、强制规则（排版层）

1. **核心摘要块（Blockquote）**
   - 报告首部用 `>` 块引用，至少包含三行：`生成时间（北京时间）` / 关键结论或验证结论 / 图例规范。
   - 正文内的"一句话核心结论"也优先用 `>` 强调。

2. **层级分明（表格 + 分级列表）**
   - 一级结论 → `>`；二级分节 → `##` + emoji 序号（如 `## 📊 一、外盘收盘定调`）。
   - 多标的、多字段对比 → **用表格**；单标的纵向展开 → 用分级列表（`*` / `-` + 2 空格缩进嵌套）。
   - 表格统一带对齐行 `| :--- | :--- |`（左对齐即可）。
   - **瘦表优先（D1b）**：宽表仅保留核心数值列（代码 / 现价 / 支撑 / 止损 / 偏离度 / 状态 / 建议动作），冗长 `trigger_condition` 等剥离到表格下方的展开卡片。

3. **操作方向用纯文字标签（红绿锁 v2.1 兼容）**
   - 买卖方向一律用加粗纯文字：**`[买入]`** / **`[卖出]`** / **`[观望]`** / **`[剔除]`** / **`[调入]`**。
   - 🔴 = 涨、🟢 = 跌，**仅表示价格涨跌方向**，不表示操作方向。
   - 🟣 主力建仓 / 🟣 主力加仓 / 🟣 主力洗盘 / 🟣 主力减仓 / ⚪ 中性 为**第三维度（主力行为）**，与涨跌色、操作方向三者严格区分；**主力行为一律 🟣/⚪，严禁用 🔴/🟢 表主力减仓**（🔴/🟢 只属于价格涨跌）。
   - 禁止用任何 HTML `<span>`/`<font>` 或内联 color 表达红绿。

4. **北京时间戳**
   - 所有时间标注 `(北京时间)`。
   - 盘后报告须在摘要块明确「**已于 15:30（北京时间）收盘后获取交易所最终清算数据**」，与运行时 `FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=15;BYMINUTE=30` 触发 + akshare 15:05 收盘闸门 + 爬虫官网权威口径一致。

5. **零裸 HTML + 文本进度条白名单（12977 防御核心 · D1a 升级）**
   - **禁止输出任何裸 HTML 标签**：`<div>` `<span>` `<br>` `<table>` `<style>` `<font>` `<img>` 等一律禁止（含 `<br>` 单元格违规）。
   - 所有排版用原生 Markdown（标题 / `>` / 表格 / `**加粗**` / 列表 / 行内代码 `code`）。
   - emoji 仅用 Unicode 字符（🔴🟢🟣⚪⚠️🔍🔎💡🚨），**不得用 `<img>` 或 `<span>` 包装**。
   - **排版用 Unicode 方块字符白名单（新增）**：`█ ▓ ░ ▒ ▰ ▱ ▮ ▯ ■ □ ● ○ ◆ ◇ ▁ ▂ ▃ ▄ ▅ ▆ ▇` 允许用于**文本进度条 / 仪表盘 / 量能分位**（纯文本字符，非图形、非 HTML）。
   - 🛡️ **防逃逸硬约束**：进度条 / 仪表盘 / 分位条**必须作为普通文本输出，严禁用代码围栏（` ``` `）或行内反引号（`` ` ``）包裹**——大模型为"美观"自发加围栏会破坏表格结构并可能触发 12977。
   - 统一标尺：量能分位以 **80 分位 = 满格基准**；情绪以 **-14 ~ +14** 为定义域（五档阈值沿用 prompt 定义）。
   - 上传通道固定 `create_smartcanvas_by_mdx` 且 `content_format=markdown`；文档标题**纯连字符/ASCII，禁用全角括号**（既有 12977 防护）。

## 三、卡片模型（Phase 2 新增 · D1b）

> 解决宽表信息过载 + 消除 `<br>` 单元格违规；统一"瘦表 + 展开卡片 + `---` 分隔"三件套。

1. **瘦表（核心数值列）**
   - 宽表仅保留：代码 / 现价 / 支撑 / 止损 / 偏离度 / 状态 / 建议动作（其余如消息面校验、量能佐证、触发条件剥离到卡片）。
   - 严禁在单元格内用 `<br>` 换行；多行说明一律移到表格下方的卡片。

2. **展开卡片（子细节）**
   - 以 `### 标的名` 起头（三级标题，区别于 `##` 章节级）。
   - 冗长 `trigger_condition` / 盘口破译 / 量能佐证 用分级列表展开在卡片内，不挤占表格。
   - 卡片内可用 `> **xxx 执行细则**：…` 强调关键动作。

3. **`---` 分隔语义重定义**
   - `##` 章节级 `---`：保留，用于大节分隔（可选）。
   - **标的间 `---`**：多标的报告里，每个 `### 标的名` 卡片之间用 `---` 分隔，形成清晰视觉断点。
   - 两者并存不冲突：章节用 `##`，标的用 `###` + `---`。

4. **既有违规修复要求**
   - 报告生成后自检：无 `<br>` 单元格、表格带 `| :--- |` 对齐行、`## 📊 一、` emoji 序号齐全、动作标签归一到 `**[买入]**` 方括号形式。

### 附录 B · MFE / MAE 三档判定（D3b）

- 输入：昨日逻辑锚定 `支撑位 S`；当日快照 `今日最低 L` / `今日最高 H` / `今日收盘 C`。
- 指标：
  - **MAE**（最大不利偏离）= `(S - L) / S`（盘中向下击穿支撑的幅度，负向）。
  - **MFE**（最大有利偏离）= `(H - S) / S`（盘中向上远离支撑的幅度，正向）。
- 三档（严禁"有效/失效"无数值依据）：
  - **有效（目标达成）**：`C ≥ S` 且 `MFE ≥ 阈值`（默认 +1.5%），目标价基本达成。
  - **部分有效（洗盘守住）**：盘中 `MAE` 短暂击穿 `S` 但 `C ≥ 止损位` 且收回复 `S` 附近，属洗盘未破坏逻辑。
  - **失效（触发止损）**：`C < 止损位` 或 `MAE` 击穿幅度 `> 止损阈值`（默认 -2.0%），逻辑被破坏。
- 输出格式（表格列）：`MAE` / `MFE` / `结果` 三列，数值精确到 0.1%。

### 附录 C · 判据吻合度替代伪概率（D3c）

- **禁止**输出"减仓 70%""概率 85%"类伪概率（无法证伪、易误导）。
- **强制**改为"置信度 + 判据共振"格式：
  - `**置信度：高 (3/3 判据共振)**` 或 `**置信度：中 (2/3 判据共振)**` 或 `**置信度：低 (1/3 判据共振)**`。
  - 紧接**判据清单**（具体、可核验）：如 `VWAP 破位 + 外盘 < 内盘 + 周K放量滞涨`。
  - 吻合数 = 命中判据数 / 总判据数（总判据按本标的设定的 2~3 条）。
- 示例：
  - ❌ `主力加仓意愿坚决 (概率 85%)`
