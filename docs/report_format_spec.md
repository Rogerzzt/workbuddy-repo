> 本文件是五套量化自动化报告（周末宏观情绪雷达 / 盘前战略预案 / 午间纠偏预警 / 盘后量化分析 / 周日热门调仓）的**唯一排版事实源**。

> 设计目标：提升美观度、扫读效率与视觉专业度；**严格规避腾讯文档 Error 12977（裸 HTML 标签报错）**。

## 一、五条强制规则

1. **核心摘要块（Blockquote）**
   - 报告首部用 `>` 块引用，至少包含三行：`生成时间（北京时间）` / 关键结论或验证结论 / 图例规范。
   - 正文内的"一句话核心结论"也优先用 `>` 强调。

2. **层级分明（表格 + 分级列表）**
   - 一级结论 → `>`；二级分节 → `##` + emoji 序号（如 `## 📊 一、外盘收盘定调`）。
   - 多标的、多字段对比 → **用表格**；单标的纵向展开 → 用分级列表（`*` / `-` + 2 空格缩进嵌套）。
   - 表格统一带对齐行 `| :--- | :--- |`（左对齐即可）。

3. **操作方向用纯文字标签（红绿锁 v2.1 兼容）**
   - 买卖方向一律用加粗纯文字：**`[买入]`** / **`[卖出]`** / **`[观望]`** / **`[剔除]`** / **`[调入]`**。
   - 🔴 = 涨、🟢 = 跌，**仅表示价格涨跌方向**，不表示操作方向。
   - 🟣 主力加仓 / ⚪ 中性 / 🔴主力减仓 为**第三维度（主力行为）**，与涨跌色、操作方向三者严格区分。
   - 禁止用任何 HTML `<span>`/`<font>` 或内联 color 表达红绿。

4. **北京时间戳**
   - 所有时间标注 `(北京时间)`。
   - 盘后报告须在摘要块明确「**已于 18:00（北京时间）后获取交易所最终清算数据**」，与运行时 `FREQ=DAILY;BYHOUR=18` + `_enforce_post_close` 物理时闸一致。

5. **零裸 HTML（12977 防御核心）**
   - **禁止输出任何裸 HTML 标签**：`<div>` `<span>` `<br>` `<table>` `<style>` `<font>` `<img>` 等一律禁止。
   - 所有排版用原生 Markdown（标题 / `>` / 表格 / `**加粗**` / 列表 / 代码 `行内代码`）。
   - emoji 仅用 Unicode 字符（🔴🟢🟣⚪⚠️🔍🔎💡🚨），**不得用 `<img>` 或 `<span>` 包装**。
   - 上传通道固定 `create_smartcanvas_by_mdx` 且 `content_format=markdown`；文档标题**纯连字符/ASCII，禁用全角括号**（既有 12977 防护）。
