# 量化数据采集自动化系统 · 重新设计方案

> 设计目标：把原"内联 16 只标的 + 单源 westock-data"的临时方案，升级为**清单外置、分时段、多源分级、结构化输出、带校验与失败日志**的可演进采集系统。

---

## 1. 标的清单管理（外置配置）

- **文件**：`<workspace>/watchlist.json`（已创建）
- **结构**：
  ```json
  {
    "version": 1,
    "updated": "2026-08-05",
    "etfs":    [ { "code": "588170", "name": "科创半导体ETF", "exchange": "SSE" }, ... ],
    "stocks":  [ { "code": "002594", "name": "比亚迪",       "exchange": "SZSE" }, ... ]
  }
  ```
- **运行时行为**：每个时段任务启动 → 读取 `watchlist.json` → 合并 `etfs + stocks` 得到全量清单 → 逐项采集。
- **变更规则**：新增/删除/改名标的，只改此 JSON；任务代码零改动。建议在 `updated` 字段标注修改日期，便于追溯。
- **健壮性**：读取失败时（文件缺失/JSON 损坏）任务中止并写 `logs/<date>/<period>_failures.log`，不静默空跑。

## 2. 分时段采集内容

### 2.1 盘前（PreMarket）· 交易日 09:20
集合竞价阶段（9:15–9:25），开盘价未最终确定，以"预判"为主。
| 维度 | 采集项 |
|------|--------|
| 隔夜外盘 | 美股三大指数（道指/纳指/标普）、热门中概、欧洲主要指数收盘表现 |
| 富时 A50 期指 | 最新点位、涨跌、与现货偏离 |
| 重磅新闻 | 央行/统计局/证监会/发改委政策、行业重大利好利空 |
| 个股公告 | 清单内标的的停牌、业绩预告、增减持、重组、问询函等 |

### 2.2 盘中（Intraday）· 交易日 14:30（尾盘）
尾盘时段数据最丰富：全天 VWAP 已成形、ETF 折溢价接近收盘值。
| 维度 | 采集项 |
|------|--------|
| 实时量价 | 最新价、涨跌幅、成交量、换手率（逐标的） |
| 分时均线 | VWAP（由分时成交量加权计算） |
| 板块轮动 | 行业/概念资金流向排名、涨跌家数、领涨/领跌板块 |
| ETF 专项 | IOPV（参考净值）、折溢价率（溢价%/折价%） |

### 2.3 盘后（PostMarket）· 交易日 15:30
收盘后，以"经核实的权威数据"为准。
| 维度 | 采集项 |
|------|--------|
| 最终收盘价 | 经交易所官网核实的收盘价（冲突以官网为准） |
| 成交量 | 日线成交量 + 周线成交量 |
| 龙虎榜 | 清单内标的上榜席位、买卖金额、机构/游资动向 |
| 融资融券 | 融资余额、融券余额（交易所官网权威） |
| 大宗交易 | 清单内标的的大宗成交价、量、折价率、买卖双方 |

## 3. 数据源与优先级（分级 + 兜底）

核心原则：**每个数据项注册一条按优先级排序的源链；采集器按序尝试，首个通过校验的即采用；全部失败 → 标记 `data_missing`，不阻断整体。**

| 数据项 | 源链（权威在前） | 冲突裁决 |
|--------|----------------|----------|
| 最终收盘价 | 交易所官网(SSE/SZSE) > 东方财富/同花顺 > westock-data | **以交易所官网为准** |
| 官方公告 | 交易所官网 > 巨潮资讯 | 官网优先 |
| ETF 申赎清单(PCF) | 交易所官网 | 官网优先 |
| ETF IOPV / 折溢价 | 集思录 > 交易所 PCF 推算 > 东方财富 | 集思录优先 |
| 盘中行情/量/换手/VWAP | 东方财富/同花顺/通达信/Wind > westock-data | 多源一致取其一，分歧告警 |
| 板块资金轮动 | 东方财富/同花顺 > westock-data | — |
| 龙虎榜 | 东方财富/同花顺/通达信/Wind > 交易所官网 | — |
| 融资融券余额 | 交易所官网 > 东方财富 | **官网为准** |
| 大宗交易 | 交易所官网 > 东方财富 | 官网优先 |
| 隔夜外盘 / A50 | 东方财富/同花顺/英为财情 > westock-data | — |
| 宏观/行业新闻 | 央行/统计局/证监会官网 + 权威媒体 > 聚合新闻 | — |

**采集器抽象（伪代码）**：
```
for item in watchlist:
    for field in item.required_fields:
        for src in source_chain(field):
            data = try_fetch(src, item, field)   # 含重试
            if validate(data):
                item[field] = data; item.source_used[field] = src.name
                break
        else:
            item[field] = None; item.warnings.append(f"{field} 全部源失败")
```

## 4. 触发时间与调度

| 时段 | 本地时间 | RRULE | 说明 |
|------|----------|-------|------|
| 盘前 | 09:20 | `FREQ=DAILY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=9;BYMINUTE=20` | 集合竞价阶段 |
| 盘中 | 14:30 | `FREQ=DAILY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=14;BYMINUTE=30` | 尾盘，可据需增 11:30 |
| 盘后 | 15:30 | `FREQ=DAILY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=15;BYMINUTE=30` | 收盘后 |

- **时区**：`Asia/Shanghai`。
- **休市跳过（强制前置检查）**：每个任务首步查询上证指数 `000001` 实时行情；**无数据 → 输出"📴 今日 A 股休市，不执行分析"并结束**。覆盖周末、法定节假日、临时休市。
- **避免重复**：在现有三套自动化上更新 prompt，不新建重复任务（此前已因重复自动化清理过一次）。

## 5. 结构化输出格式与文件命名

### 5.1 目录结构
```
<workspace>/
  watchlist.json
  data/
    pre/     <YYYYMMDD>/pre_<YYYYMMDD>.json
    intraday/<YYYYMMDD>/intraday_<YYYYMMDD>_1430.json

  logs/

```

### 5.2 命名规则
- 机器数据：`<period>_<YYYYMMDD>[_HHMM].json`，`period ∈ {pre, intraday, post}`
- 失败日志：`logs/<YYYYMMDD>/<period>_failures.log`
- 运行清单：`logs/<YYYYMMDD>/<period>_manifest.json`

### 5.3 主 JSON Schema（示例）
```json
{
  "meta": {
    "period": "post",
    "trade_date": "2026-08-05",
    "generated_at": "2026-08-05T15:30:12+08:00",
    "status": "partial",
    "source_attribution": { "close": "SSE", "lhb": "eastmoney", "margin": "missing" }
  },
  "watchlist_summary": { "etf_count": 6, "stock_count": 10, "ok": 14, "partial": 2, "failed": 0 },
  "items": [
    {
      "code": "002594", "name": "比亚迪", "type": "stock", "exchange": "SZSE",

        "volume_week": 65432109, "lhb": {...}, "margin": null

                        "warnings": ["margin: 全部源失败 -> data_missing"] }
    }
  ],
  "market": { "index": {...}, "sector_rotation": [...] },
  "failures": [ { "code":"002594", "field":"margin", "tried":["SSE","eastmoney"], "error":"timeout" } ]
}
```

## 6. 数据校验、异常重试与失败日志

### 6.1 校验（逐项，采集后立即执行）
- **结构**：必填字段存在；`code/name/type/exchange` 与清单一致。
- **数值合理性**：`price > 0`；`volume >= 0`；`turnover_rate ∈ [0,100]`；`close` 较前收偏离超过 **±20%** 即告警（疑似除权/数据异常，如 159813 曾现 -52% 接口 bug）。
- **时间戳新鲜度**：盘中/盘后行情时间距执行时间不超过 **N 分钟**（盘后放宽至当日），否则标 `stale`。
- **跨源一致性**：若 ≥2 源成功且差异超阈值 → `warning`（不覆盖，保留两源值）。

### 6.2 重试
- 每源**指数退避**：base 2s，最多 **6 次**（westock-data 实测首次常返回空，需重试 1–6 次）。
- 单源全部重试失败 → 切换下一源；所有源失败 → 标 `failed`，**继续下一项，不中断整体运行**。

### 6.3 失败日志
- 追加写 `logs/<date>/<period>_failures.log`：`[时间] code | field | tried=[src1,src2] | error=...`
- `manifest.json` 汇总：`ok / partial / failed` 计数 + `source_attribution`（每个字段实际采用来源），供事后审计与配额优化。

## 7. 当前环境数据源可用性核查（落地前必读）

| 数据源 | 状态 | 设计中的角色 | 落地动作 |
|--------|------|--------------|----------|
| **westock-data**（腾讯自选股 skill）| ✅ 可用 | 兜底：行情/量/换手/资金流/kline/龙虎榜/板块/涨跌家数 | 直接可用 |
| 交易所官网(SSE/SZSE) | ❌ 需接入 | 收盘价/公告/PCF/融资融券/大宗 权威源 | 需爬虫或官方开放接口 |
| 集思录 | ❌ 需接入 | ETF IOPV/折溢价 | 需爬虫 |
| 东方财富妙想MCP | ⚠️ 未连接 | 行情/龙虎榜/资金/外盘 | 连连接器 |
| 同花顺快查 | ⚠️ 未连接 | 企业数据为主，非实时行情 | — |
| 通达信 | ⚠️ 未连接 | 盘中行情 | 连连接器 |
| Wind | ⚠️ 未连接（付费）| 全维度专业终端 | 连连接器 |
| 腾讯文档 | ⚠️ 当前未连接 | 上传人读报告 | 需重连 |

**结论**：当前**唯一稳定可取数源是 westock-data**。设计方案已内置降级——缺失源标注 `data_missing` 并写失败日志，不会让任务崩溃。但要**完整覆盖你的需求清单**（尤其公告、融资融券、大宗交易、IOPV/折溢价、隔夜外盘/A50），需先接入对应连接器或爬虫。

## 8. 三套自动化 Prompt 模板（可直接粘贴）

> 以下为骨架；`{{...}}` 由调度注入。当前仅 westock-data 可用，模板中以它为主路径，并在注释标出其他源的接入点。westock-data 调用格式（node）：
> `node <westock-path>/scripts/index.js quote <code>` 等。

### 8.1 盘前（09:20）
```
你是一名 A 股盘前量化助手。请按以下步骤执行（交易日才运行）：

0) 休市检查：查询上证指数 000001 实时行情；无数据 → 输出"📴 今日 A 股休市"并结束。
1) 读取 <workspace>/watchlist.json，合并 etfs+stocks 为全量清单。
2) 逐项/批量调用 westock-data 获取：隔夜外盘（market-overview / 对应指数）、
   富时 A50（如支持）、清单内个股公告（公告接口）。缺失源标注 data_missing。
3) 采集重磅宏观/行业新闻（可用 web 检索权威来源）。
4) 输出结构化 JSON 到 data/pre/<date>/pre_<date>.json（按第5节 Schema）。
5) 生成人读 Markdown 摘要；若腾讯文档已连接则上传并输出链接，否则保存本地。
6) 任何单源失败：重试≤6次（指数退避），仍失败写 logs/<date>/pre_failures.log，继续下一项。
```

### 8.2 盘中（14:30）
```
A 股盘中量化助手。步骤：

0) 休市检查（同上）。
1) 读取 watchlist.json 全量清单。
2) 调用 westock-data 获取逐标的实时价/涨跌幅/成交量/换手率（quote）、
   板块资金轮动（sector ranking）、涨跌家数（changedist）。
3) VWAP：用分时数据按成交量加权计算（源支持时）；否则标注。
4) ETF IOPV/折溢价：优先集思录（接入后），否则标注 data_missing。
5) 输出 data/intraday/<date>/intraday_<date>_1430.json + Markdown 摘要（上传/本地）。
6) 重试≤6次，失败写日志，不中断。
```

### 8.3 盘后（15:30）
```
A 股盘后量化助手。步骤：

0) 休市检查（同上）。
1) 读取 watchlist.json 全量清单。
2) 收盘价：优先交易所官网（接入后），当前用 westock-data quote --date <date> 并标注"未官网核实"。
3) 日线/周线成交量（kline）；龙虎榜（lhb，用带市场前缀代码 sz/sh 匹配）；
   融资融券（官网优先，缺失标注）；大宗交易（官网优先，缺失标注）。
4) 板块/市场多维诊断。
5) 输出 data/post/<date>/post_<date>.json + Markdown/HTML 报告（上传/本地）。
6) 重试≤6次，失败写日志，不中断。
```
