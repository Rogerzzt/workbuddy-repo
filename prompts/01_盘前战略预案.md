## 报告排版规范（行政研报级 · 强制）

1. **首部摘要块**：报告首部用 `>` 块引用，至少三行——`生成时间（北京时间）` / 关键结论或验证结论 / `图例规范`（操作方向纯文字、🔴🟢仅表价格）。
2. **层级结构**：一级结论用 `>`；分节用 `## 📊 一、xxx` 形式的 emoji 序号标题；多标的多字段对比一律用**表格**，单标的纵向展开用分级列表（2 空格缩进嵌套）。

4. **北京时间戳**：所有时间标注 `(北京时间)`。
5. **零裸 HTML（12977 防御核心）**：禁止输出 `<div>/<span>/<br>/<style>/<font>/<img>` 及任何内联颜色或锁形图标；emoji 仅用 Unicode。上传统一 `create_smartcanvas_by_mdx` + `content_format=markdown`，标题纯连字符/ASCII、**禁用全角括号**。
6. **Phase 2 增强（D1a/D1b）**：量能分位/情绪用文本进度条（如 `20日量能位置: [████████░░] 82% 放量`，Unicode 方块字符 `█▓░▒`，**普通文本、严禁代码围栏/行内反引号包裹**）；宽表瘦表 + 标的间 `---` 卡片分隔（卡片以 `### 标的名` 起头，冗长 `竞价场景触发条件` 剥离到卡片）。详见 `docs/report_format_spec.md` 一.5 与 三。
7. **Phase 3 增强（2026-08-17 · 附录 E）**：执行细则用**三标签卡片**（**【执行指令】** / **【熔断条件】** / **【逻辑依据】**，加粗+【】标签，禁用行内代码块）；「综合开盘预期」末尾输出**【今日建议仓位】**（三因子规则化映射，禁止主观拍百分比）。格式详见 `docs/report_format_spec.md` 附录 E。

报告结构（**开盘竞价方案必须置于最前，这是本报告的核心产出**）：

### 一、开盘竞价方案（核心）
针对每只 A 级标的，输出一行可执行指令，必须包含：
| 标的 | 昨日信号方向 | 消息面校验 | 竞价场景触发条件 | 建议动作 | 竞价介入参考价 | 止损位 |
- **消息面校验**：结合步骤 4 查到的个股新闻与隔夜宏观，判定昨日信号是「强化 / 中性 / 证伪」
- **竞价场景触发条件**：本任务 08:30 运行，集合竞价（9:15-9:25）尚未开始，故本列给出**条件式触发指令**（必须给具体竞价价格阈值或涨跌幅阈值，禁止填「—」），由投资者在 9:15-9:25 观察竞价价格对照执行；例如「竞价高开 >+3%：放弃不追」「竞价平开/小幅低开：回踩不破支撑则竞价介入」「竞价大幅低开跌破止损：信号取消」
- **⚠️ 竞价熔断机制（硬规则，无条件执行）**：无论盘前判断多么看多，只要开盘出现以下任一极端场景，**当日所有买入计划（竞价介入/回踩挂单）一律无条件作废，原挂单价方案不再执行**：① 标的竞价一字跌停（买一价=跌停价且封单）；② 标的竞价低开 >5%（竞价价较昨收跌幅超 5%）。此时该标的「建议动作」改为「信号取消放弃/卖出」，并在表格「竞价场景触发条件」列显式写明「触发熔断：低开>5%（或一字跌停），放弃买入」。目的：防止恐慌盘口盲目承接。
- **建议动作**：从 {竞价直接介入 / 回踩支撑挂单 / 观望等突破 / 信号取消放弃} 中明确选一个，并给出一句话理由
- **操作方向标记**：建议动作=竞价直接介入 / 回踩支撑挂单 / 观望等突破 → 该行「建议动作」前写「买入」；建议动作=信号取消放弃（消息面证伪）→ 写「卖出」；无 A 级标的时跳过本节
- **竞价介入参考价**：给具体数字，来源于 strategy_state 的 support_levels 与隔夜消息综合修正；即投资者在竞价阶段可接受的委托价区间
- **周一情绪防御（联动 weekend_sentiment）**：若今天是周一（date +%u == 1）且 weekend_sentiment 整体为「极度悲观」，或某 A 级标的所属板块在 sector_warnings 中 bias=「偏空」→ 该标的挂单价必须主动下移至强支撑位附近（取 support_levels 中更低一档），或直接由「竞价直接介入/回踩支撑挂单」改为「观望等突破」，并在建议动作中写明理由（如「周末医药集采偏空，挂单价下移至强支撑 0.66，或直接观望」）
- **止损位**：继承 strategy_state 的 stop_loss，若隔夜重大利空则相应下修并说明

**执行指令三标签卡片（Phase 3 · 附录 E · 强制，表格下方逐标的输出）**：在「开盘竞价方案」表格之后，为每只 A 级标的输出一张执行细则卡片，将委托指令从叙述中剥离为**固定三标签结构**（全部加粗+【】标签，**禁止行内代码块/反引号/HTML**；箭头用 `→`，区间用 `~`，数值与阈值一律加粗）：
```
### 588170 科创半导体ETF（竞价执行细则）
* **【执行指令】**回踩不破 0.998 → **挂单买入区间 0.998~1.003**
* **【熔断条件】**高开 >+3%（1.052）放弃；低开 >5%（0.970）无条件撤单
* **【逻辑依据】**昨收 1.021 > MA20，量能缩量，守支撑持有
```
三标签定义：**【执行指令】**=具体委托动作+价位区间（竞价直接介入/挂单买入区间/卖出委托价/观望触发价）；**【熔断条件】**=竞价熔断阈值（一字跌停、低开>5%）+标的级失效条件（跌破止损位 X）；**【逻辑依据】**=一句话说明信号来源（昨日机械信号档位 × 消息面校验结论）与价位推导依据。禁止把挂单价埋进叙述段落而不加标签。

若消息面证伪（如出现重大利空公告、行业政策转向）→ 必须明确写「信号取消，今日放弃该标的」，不要含糊。
若无 A 级标的 → 写明「昨日无触发信号，今日以观察为主」，并跳过本节表格与卡片。

### 二、隔夜外盘与情绪指向
主要指数涨跌（含日经225）、A50期指、对A股开盘情绪的指向判断（偏多/偏空/中性 + 理由）。
本节末尾（**综合开盘预期之后**）必须输出**【今日建议仓位】**（Phase 3 · 附录 E 仓位水位线，**规则化映射，禁止主观拍百分比**）：基准 50%，三因子各 ±10 个百分点，最终钳位 20%~80%——
- **情绪得分因子（仅周一取值，非周一计 0）**：weekend_sentiment 综合情绪分 sentiment_score ≥ +3 → +10；≤ −3 → −10；其余 0（文件缺失亦计 0 并标注）
- **昨日触发面因子**：strategy_state 偏多触发 ≥3 只 → +10；偏空触发 ≥3 只 → −10；其余 0
- **大盘趋势因子**：sh000001 昨收 > MA20 → +10；< MA20 → −10；数据缺失计 0 并标注
输出格式（固定）：`**【今日建议仓位】**：40%~50%（判据：情绪+3 / 触发面中性 / 大盘于 MA20 下方）仅供参考，不构成投资建议`。**只给区间不给精确值**，判据必须列出三因子各自贡献，方便复核。

### 三、重磅消息
宏观政策、行业动态、清单标的公告（无重要公告则明确写「无」）

### 四、全清单关键价位表（Phase 4 · 含资金攻防预期）
清单每只标的的昨收、支撑位、压力位（基于5日K线计算，说明计算依据；**A 级标的若昨日 JSON 含 next_day_levels，以盘后推演值为第一手来源并与K线计算值并列，优先采用**），A 级标的加标记区分。**表格必须新增两列（Phase 4 硬要求）**：

| 级别 | 标的 | 昨收 | 支撑位 | 压力位 | 距离压力% | 资金攻防预期 (压力/支撑成因) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **A级** | 588170 科创半导体 | 1.021 | 0.998 | 1.050 | 距压 2.8% | 压力：前期密集套牢盘，突破需放量；支撑：5日均线与昨日大单承接位 |

- **距离压力%** = (压力位 − 昨收) / 昨收，保留两位小数百分比（衡量今日上行空间）
- **资金攻防预期**：单行纯文本，用「压力：…；支撑：…」分号分隔，解释该点位的抛压/承接来源（密集套牢盘/前高颈线/均线/跳空缺口/大单承接位等）；**严禁 `<br>` 等任何 HTML 标签**（12977 防御），单元格内不得换行
- 攻防预期措辞须可追溯：来自 5 日K线形态、昨日 next_day_levels.basis 技术依据、或爬虫/行情源的大单与量能数据；取不到依据写「常规技术位」

### 五、数据来源与验证
三源交叉验证结论、继承的 strategy_state 文件名与日期、A 级标的数、仓位水位线三因子取值来源、**A 级标的 next_day_levels 继承情况（含/不含，缺哪些）**；若为周一，另注 weekend_sentiment 文件名与评级、以及步骤1要求的状态继承记录。
