### 主力行为判定框架（盘口语言 · 量价行为学 · 盘后适配版）
> 将「主力行为档位」从单维资金流升级为可证伪的盘口语言拆解。本框架独立于涨跌色（🔴/🟢 仍仅表价格方向），
> 也不与 aquant 的 MA20/量能触发条件耦合——它是对"当日资金意图"的独立定性判定，可与 aquant verdict 互证或提示背离。

**盘后可取数据**：分时形态（data_minute，days=1）、内外盘（data_quote，外盘>内盘=主动买盘强）、
大单/超大单净额（fund_flow，主买主卖方向）、量能位置（vol_ratio/量比）、价格位置（aquant MA20 / 近期高低）、
龙虎榜（data_lhb，若上榜看机构/游资净买卖做交叉验证）。

**核心判定基准（单日盘面特征对比 · 盘口破译逐条对照此表）**：
| 盘面指标 | 🟣主力建仓 | 🟣主力加仓 | 🟣主力减仓(派发) | 🟣主力洗盘 |
| --- | --- | --- | --- | --- |
| 分时图走势 | 脉冲式尖角拉升后缓慢回落（试探抛压）；全天多数时间沉闷 | 阶梯式/45°平稳向上，回调极少破均价线，走势流畅 | 早盘急拉后迅速跳水（诱多）；或全天受制于均价线下方震荡 | 剧烈震荡、长上/下影，急杀后快速收回均价线之上 |
| 成交量配合 | 底部温和放量，涨有量、跌缩量极度萎缩 | 上涨伴随量柱密集放大，量价齐升，推升坚决 | 高位放巨量（常对倒）或"天量滞涨" | 放量不跌或缩量小跌 |
| 盘口挂单 | 大单压盘：上方卖区挂大单压价，下方小单悄悄吃进 | 撤单扫货：压盘被迅速撤销/大单一口吃掉，外盘激增 | 大单托盘：下方买区挂满大单制造跌不下去假象，上方内盘不断砸出 | 压单与托单交替，整体未持续撤离 |
| 尾盘动作 | 尾盘几分钟少量资金打压，制造恐慌、做低次日开盘价 | 尾盘抢筹拉升，甚至封板，为次日溢价准备 | 尾盘偷袭拉高（画线造势），低成本维持形态掩护次日出货 | 尾盘不深跌、守住关键位，清洗浮筹 |

**单日评估 3 个关键维度（盘口破译必用）**：
1. 分时均价线（VWAP）支撑/阻力：强势=股价全天在均价线上方、回调触及即反弹（护盘买入）；弱势=早破均价线后多次反抽无力突破，均价线由支撑变阻力（派发）。
2. 真实主动性买卖（内盘 vs 外盘）：上涨且外盘显著>内盘+大单买入 → 加仓；大幅震荡/微涨但内盘远大于外盘+频现大单砸出 → 减仓/清仓（警惕对倒欺骗，勿只看过账成交额）。
3. 结合股票所处空间位置：低位震荡区大单压盘脉冲放量 → 建仓；突破关键阻力位（颈线/均线密集区）坚决持续大单买入量价齐升 → 加仓；主升浪末端/连续暴涨后尾盘拉升+巨量宽震+下方大单托盘 → 极大概率减仓。

**辅助验证工具**：Level-2 十档/千档盘口看"大单净流入/流出"指标；盘后龙虎榜（若上榜）看机构席位与知名游资净买卖，为当日盘口观察提供直接交叉验证。

**5 档速判（与基准表对应）**：
- 🟣主力建仓：符合上表"建仓"列特征，多见于低位震荡区（价格未涨、资金先动）。
- 🟣主力加仓：符合上表"加仓"列特征，多见于突破关键阻力位（原有仓位上追加）。
- 🟣主力减仓（派发）：符合上表"减仓"列特征，多见于主升浪末端/连续暴涨后（边拉边撤）。
- 🟣主力洗盘：符合上表"洗盘"列特征，上涨途中震而不破（清洗浮筹）。
- ⚪主力中性：净流入≈0、量能平稳、内外盘均衡、分时无典型形态 → 不标特殊档位。

**盘口破译四步（每触发/重点标的必做）**：
1. 🔍核心结论：一句话判定主力最可能动作（建仓/加仓/减仓/洗盘/中性）+ 概率%（如"减仓 70%"）。
2. 🔎盘口破译：逐条对照上表"核心判定基准"与"3 关键维度"，用取到的数据（分时形态+内外盘+大单+量能+价格位置+龙虎榜）举证，每条判据标注来源；无法取证写「数据缺失」，禁止臆造。
3. ⚠️虚假信号排查：识别骗线——"早盘急拉无量=诱多""尾盘偷拉造势=次日派发""大单托盘但内盘持续>外盘=掩护出货""缩量假突破"；给"真实信号/诱多/诱空"判定。
4. 💡应对策略：基于动作给短线+中线建议（持股观望/均线低吸/逢高减仓/破位止损），与 aquant 操作依据并列；冲突时提示"主力动作与量价信号背离"。

标记写入「标的快照」表的「主力行为」列（🟣主力建仓/🟣主力加仓/🟣主力减仓/🟣主力洗盘/⚪中性），可在「操作依据」行首与文字买卖并列（如「🟣主力减仓 · 卖出」）。禁止使用 HTML `&lt;span&gt;`。

报告分四部分：
1. **标的快照**：清单全部标的的收盘价、涨跌幅、成交额、换手率、主力净流入（含超大单/大单分项）、**主力行为档位（🟣建仓/🟣加仓/🟣减仓/🟣洗盘/⚪中性）**、ETF 折溢价率；每项标注数据来源

4. **量价信号与操作依据**（核心，勿省略）：先列 aquant 信号表（MA20 趋势 + 量能异常-动态分位数），对【触发标的】与【重点未触发标的】逐只给出：a.成交量解读（放量是否主力驱动、量能可持续性、量比位置）b.板块定位（板块强弱、是否共振）c.基本面校验（业绩趋势、估值分位、公告催化）d.操作依据（偏多/偏空/观望 + 关键支撑/压力位/止损位）e.主力行为印证（用 🟣主力建仓/🟣主力加仓/🟣主力减仓/🟣主力洗盘 印证 aquant verdict：建仓/加仓与偏多互证、减仓与偏空互证、洗盘则"震而不破"可持有；若 aquant 偏多但主力净流出/减仓，显式提示「量价与主力背离，谨慎」；若 aquant 偏空且主力减仓，则相互确认）；触发/重点标的须附「盘口破译四步」（🔍核心结论+🔎盘口破译+⚠️虚假信号排查+💡应对策略），末尾标注「仅供参考，不构成投资建议」；其余标的一句话带过

## 步骤 7：闭环状态机 —— 写入 strategy_state_YYYYMMDD.json
报告生成后，额外产出机器可读状态文件，供次日盘前/盘中继承：
路径：data/strategy_state_YYYYMMDD.json
结构示例：
```json
{
  "date": "YYYY-MM-DD",
  "triggered_tickers": [
    {"code":"588170","name":"科创半导体ETF华夏","bias":"偏多",
     "support_levels":[0.916,0.83],"resistance_levels":[1.0,1.06],"stop_loss":0.83}
  ],
  "support_levels": {"588170":[0.916,0.83]},
  "resistance_levels": {"588170":[1.0,1.06]},
  "review": null
}
```
提取规则：从步骤6「量价信号与操作依据」中挑出 verdict=偏多/偏空的触发标的，写入 triggered_tickers（含支撑/压力/止损位，数值取自报告分析，须可核对）；support_levels/resistance_levels 为全量标的最关键一档支撑/压力。用 Python 或 jq 写文件，确保合法 JSON，数值不得编造。

## 步骤 8：昨日策略复盘（持续优化闭环）
读取 data/ 目录中文件名日期最大（即最近一个交易日）的 strategy_state_*.json（上一交易日的闭环状态；若不存在则跳过本步）：
- 对其每个 triggered_ticker，结合今日真实行情（爬虫/行情源取到的收盘、最低、最高）判定：
  - 支撑守住：今日最低 >= 支撑位 → 「守支撑」
  - 压力突破：今日最高 >= 压力位 → 「破压力」
  - 破位：今日最低 < 止损位/支撑位 → 「破位」
- **策略复盘表格格式（硬约束，违反即视为不合格）**：「策略复盘」小节必须以**表格**呈现，且**每行必须同时包含「代码」与「名称」两列**（示例：`603011 | 合锻智能`），禁止只放代码无名称、也禁止只放名称无代码；单一「标的」列只写代码、或复盘只列失效项/只列 A+B 子集，均视为不合格。复盘须覆盖昨日闭环状态**全量**标的（偏多+偏空+观望），逐只给出：昨日判定 / 今日最低·最高·收盘 / 结果（守支撑·破压力·破位·翻空等）/ 是否有效，并补充「昨日主力行为 → 今日主力行为」对照列（🟣建仓/🟣减仓/⚪中性），观察主力意图是否延续。
- 统计信号胜率（守住+突破数 / 总数），写入今日报告「策略复盘」小节，并把 review 结果（hit_rate + 每标的 details，**details 必须含 code 与 name 两个字段**）回填进当日 strategy_state_YYYYMMDD.json 的 review 字段。
- **策略复盘操作标注**：「策略复盘」小节中判定为「破位」的标的，在「结果」列用纯文字标注「失效/卖出」；守支撑/破压力标注「有效/偏多有效」等，均不用红绿着色或锁形图标；后续调参（如分位数阈值 0.8）可参考胜率数据。

## 已知问题（勿浪费时间重试）
- **调度器不解析 rrule 的 BYDAY**：周末与节假日一定会触发，靠步骤 0 两道闸门拦截，不要以为是手动运行
- 北向资金已停止盘中披露，期指数据 westock 不支持 → 直接标注数据缺失
- 两融为 T-1 数据，盘后拿到的是上一交易日，属正常
- 非两融标的无融资融券数据，属正常
- westock kline 批量查询恒返回空 → 必须逐只单独查；且不要加 --limit 参数，用裸命令 kline <code>
- aquant 脚本仅提供量价信号，不做解读；解读与建议由本任务完成，勿重跑信号逻辑
- **腾讯文档上传禁止 HTML `<span>` 颜色标签**：smartcanvas 接口无法解析 HTML，会返回 12977「create empty smartcanvas failed」导致上传静默失败；涨跌一律用 🔴/🟢 emoji 或「+x% / −x%」纯文字标注
- **红绿语义唯一性（防混淆硬约束）**：🔴/🟢 在本报告中**仅表示价格涨跌（涨红跌绿）**；操作方向（买入/卖出/观望）一律用**纯文字**，禁止用锁形图标或红绿着色表示买卖，避免与涨跌色混淆。违反此条即视为报告不合格。
- **腾讯文档标题禁用全角括号（）**：同样会触发 12977 静默失败；标题用半角()或纯文件名风格（如「盘后量化分析-20260806」），勿直接套用报告 H1（其常含全角括号）
