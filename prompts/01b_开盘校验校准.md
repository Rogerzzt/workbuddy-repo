# 审计副本 · 开盘校验校准（策略闭环·开盘后修正）
> 本文件为 `automation-*` 运行时 prompt 的 Git 审计副本。修改请以 `automation_update`（带前缀 id）为准，本副本仅用于版本留痕，同步由脚本/人工维护。

## 通用前置 · 目录锚定（每次运行最先执行，严禁假设当前工作目录）
无论自动化调度引擎把工作目录（CWD）设成了哪里（项目根 / 用户家目录 ~ / 或其他），本任务**强制先把工作目录锚定到项目根**，再执行任何文件读写，避免相对路径错位导致读不到 watchlist、或把数据写飞到错误位置。
  export WS="${AQUANT_WORKSPACE:-/Users/rogerz/WorkBuddy/金融分析报告}"
  cd "$WS"
  [ -f config/watchlist.json ] || { echo "❌ 目录锚定失败：在 $(pwd) 下未找到 config/watchlist.json，请检查 AQUANT_WORKSPACE 环境变量或项目路径"; exit 1; }
  echo "📁 工作根目录已锚定: $(pwd)"
此后所有 data/ 、 config/ 、 scripts/ 相对路径均相对 $WS 解析（已 cd 进去，等价）。若需显式写绝对路径，统一用 $WS/ 前缀，例如 "$WS/data/strategy_state_YYYYMMDD.json"。
本条为防御性双重保险：正常情况下本自动化 cwds 已是项目根，此步专防环境漂移 / 手动运行 / 引擎升级导致 CWD 偏移。

## 容错总则（防静默无输出 · 强制）
本任务任何环节都不得因上游异常而整轮无产物。硬性规则：
1. 连接器失败必须降级而非中断：若某 MCP 连接器（含 neodata-financial-search）调用报错 / 返回不可用 / token 过期，立即将该环节标记为「🔴数据缺失」，改用替代源（其他可用 MCP 或 WebSearch 网络检索）继续，禁止 exit / 禁止整轮中止。
2. 交付物必须落盘：即使数据采集仅部分成功，仍须生成并保存本次报告/预案，失败环节用 🔴数据缺失 明确标注，绝不允许「无输出」。
3. 腾讯文档上传工具可能未在本会话暴露：若 create_smartcanvas_by_mdx（或 tdoc_call 封装）不可用，直接降级本地保存并说明，不要重试或卡死。

A 股开盘校验与挂单价校准。所有数据必须真实采集，禁止编造任何数字；采集不到就明确标注「数据缺失」。

本任务是策略闭环的**第二环补丁**：盘前 09:00 已产出《盘前战略预案-YYYYMMDD.md》（基于昨收支撑与理论价位的开盘前预判）。本任务在**真实开盘价产生后（9:25 集合竞价撮合确定，本任务调度时间已预留提前量，实际约 09:26–09:31 触发，确保晚于 9:25）**重跑，用真实今开校准挂单价与止损位，修正 09:00 预判与真实开盘的偏离。

## 步骤 0：交易状态前置检查（两道闸门，必须先做）
**闸门一（周末速退）**：运行 `date +%u`。若输出为 6 或 7（周六/周日），**立即输出一行「周末休市，跳过」并结束**，不得调用任何行情接口、爬虫或 MCP。调度器不支持 rrule 的 BYDAY 过滤，周末必然误触发，本闸门是唯一拦截手段。
**闸门二（节假日检查）**：工作日才执行——用腾讯自选股 data_quote 查 sh000001（上证指数）。若返回为空或最新日期非今日 → 判定为法定节假日/临时休市，仅输出一行休市通知并立即结束。

## 步骤 1：读取盘前预案与策略状态（校准基准）
- 读取今日 `盘前战略预案-YYYYMMDD.md`（09:00 产物）作为**校准基准**——逐只提取 A 级标的的「盘前预判挂单价」「盘前预判止损位」「建议动作（红绿锁）」「消息面校验」。
  - 若该文件不存在（如 09:00 任务失败）→ 降级：读取 data/ 下**文件名日期最大且实际存在**的 `strategy_state_YYYYMMDD.json`，按盘前预案同款继承逻辑重建 A 级标的清单，并在报告中标注「无盘前预案，已用 strategy_state 重建基准」。
- 读取 `config/watchlist.json`（勿内联硬编码代码）。

## 步骤 2：采集真实今开（核心，9:25 后口径）
- 通达信 `tdx_quotes`：取全部清单标的的**今日开盘价（open）与最新价**；**校准只用开盘价（9:25 撮合价），勿用最新价替代**。
- 腾讯自选股 `data_quote`：交叉校验开盘价。
- **三源交叉验证（强制）**：对 A 级标的，用 交易所官网（爬虫 skill `scraper.py --period intraday` 或 `pre`）、腾讯自选股、通达信 三源比对**今日开盘价**，容差 0.5%；不一致以交易所官网为准并标注。
- 若接口返回的「今日开盘价」日期非今日（极早触发或数据未更新）→ 该标标记为「今开未定（数据缺失）」，沿用盘前预判并标注，不强行校准。

## 步骤 3：校准逻辑（每只 A 级标的）
设 盘前预判挂单价 `P`、盘前预判止损位 `S`、真实今开 `O`：
- **买入信号（🔒红）校准**：
  - `O ≤ P` → 开盘未高开、仍在预判介入区，维持 🔒买入，挂单价维持 `P`（或微调至 `O` 与支撑之间）。
  - `P < O ≤ P × 1.02`（小幅高开）→ 维持 🔒买入，但挂单价上修至「今开回踩支撑」档，提示不追高。
  - `O > P × 1.02`（大幅高开）→ 追高风险骤增，建议动作改为「观望等回踩」（红绿锁可维持🔒红、动作=观望，或依纪律降为🔒绿放弃），写明理由。
- **卖出/止损信号（🔒绿）校准**：
  - `O ≤ S`（低开破止损）→ 止损纪律触发，确认 🔒卖出/放弃，止损位下调至 `O` 下方。
  - 否则维持原判断。
- 校准后**止损位**一律以 `O` 重算：止损 = `O − (P − S)` 区间，或取支撑位更低一档，并在表中写明依据。
- B 级标的：仅给出「今开 vs 昨收」涨跌幅，不做挂单校准（资源倾斜 A 级）。
