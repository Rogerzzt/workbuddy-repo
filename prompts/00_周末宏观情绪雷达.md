## 步骤 1：读取持仓与策略基准
读取 config/watchlist.json（标的清单唯一事实来源，勿内联）。
读取 data/ 下文件名日期最大的 strategy_state_YYYYMMDD.json（最近一个交易日，通常即上周五）。
提取 A 级标的：triggered_tickers 中处于触发持仓状态的标的。判断规则：若标的含 `status` 字段且为 TRIGGERED_NEW / TRIGGERED_CONT → 计入；当前 strategy_state 以 `bias` 字段标记，凡 bias 非空且非「观望」（即偏多/偏空）者视为持仓中的触发标的，同样计入 A 级。
记录每只 A 级标的的 code / name / bias / support_levels / resistance_levels / stop_loss，并判断其所属板块（ETF 看名称主题，如半导体/科创/通信/电网/医药；个股看申万行业），供步骤 3、4 板块预警使用。

## 步骤 2：周五外盘定调 (MCP: 腾讯自选股)
用腾讯自选股 data_quote 获取美股三大股指与费城半导体指数周五最终收盘涨跌幅：
- 道指 usDJI、纳指 usIXIC、标普500 usINX

## 步骤 3：周末 72 小时重磅消息挖掘 (MCP: NeoData)
使用 NeoData 金融搜索，**必须明确指定回溯过去 72 小时（覆盖周五盘后至周一早晨）**：在查询句中显式带上时间窗，例如「过去72小时」「2026年M月D日至M+2日」。

**动态查询句（消除数据孤岛，挂载 A 级标的真实板块）**：步骤 1 已为每只 A 级标的判定了所属板块（半导体/科创/通信/电网/医药/个股申万行业等）。本步骤**不再使用固定产业查询句**，而是依据这些真实板块动态拼接：
- 查询句 1（宏观，固定）："证监会 央行 发改委 周末 过去72小时 重磅政策 降息降准 房地产 资本市场"
- 查询句 2（产业，按板块动态拼接）：对步骤 1 提取到的每个**去重板块**，各发一条 `"<板块> 周末 过去72小时 行业 利好 利空 消息"`（如同时含半导体与医药，则分别发 `"半导体 周末 过去72小时 行业 利好 利空 消息"` 与 `"医药 周末 过去72小时 行业 利好 利空 消息"`），避免查询与实际持仓脱节。

NeoData 凭证由脚本自动管理（12h 缓存）；若提示 TOKEN_MISSING/TOKEN_EXPIRED，调用 connect_cloud_service 取 tempToken 后 --save-token 重试一次。

## 步骤 4：情绪评级与 JSON 写入（含定量锚点）
综合步骤 2（外盘）+ 步骤 3（消息），先按下方「情绪定量锚点」算出综合情绪分 S，再映射为五档评级，禁止凭空拍脑袋。

### 情绪定量锚点（强制，先算分再定档）
① 外盘子分（基于步骤2取到的周五涨跌幅，单位 %）：
   对每个指数按区间映射：<-1.5 → -2；-1.5~-0.5 → -1；-0.5~+0.5 → 0；+0.5~+1.5 → +1；>+1.5 → +2
   - 道指 usDJI、纳指 usIXIC、标普500 usINX：各取映射值（+2~-2）
   - 费城半导体指数：映射值 ×2（+4~-4，对 A 股科技板块影响权重加倍）
   外盘子分 = 道指 + 纳指 + 标普 + (半导体×2)，范围 -10 ~ +10
② 消息面子分（基于步骤3挖掘，每个事件 -2~+2，可叠加）：
   - 宏观：降准降息/重磅刺激/监管利好 → +1~+2；收紧/打压/突发事件 → -1~-2
   - 产业/个股（针对清单标的或其板块）：集采/政策打击/业绩暴雷 → -1~-2；重磅订单/政策扶持/业绩超预期 → +1~+2
   消息面子分 = 宏观分 + 产业个股分，范围 -4 ~ +4
③ 综合情绪分 S = 外盘子分 + 消息面子分，范围 -14 ~ +14
④ 五档映射（以 S 为准；边界可结合未量化定性因素微调 ±1 档，但须在报告与 JSON 中注明）：
   - S ≤ -7 → 极度悲观
   - -6 ≤ S ≤ -2 → 偏空
   - -1 ≤ S ≤ +1 → 中性
   - +2 ≤ S ≤ +6 → 偏多
   - S ≥ +7 → 极度亢奋

将该评级写入 data/weekend_sentiment_YYYYMMDD.json（YYYYMMDD 为当日周一日期），结构：
{
  "market_sentiment": "偏多",
  "sentiment_score": 6,
  "key_drivers": ["外盘半导体大涨", "周末出台刺激消费政策"],
  "sector_warnings": [{"sector": "医药", "bias": "偏空", "reason": "集采降价超预期"}]
}
- market_sentiment 必须是五档之一，不得自造；
- sentiment_score 为上面算出的整数 S，必须如实填写（禁止编造与子项不一致的分数）；
- key_drivers 为字符串数组，列 2~5 条核心驱动；
- sector_warnings 为对象数组，对清单相关且偏空的板块给 bias（偏空/偏多）+ reason；无则空数组 []。
用 Python（受管 venv）或 jq 写文件，确保合法 JSON；文本/数值不得编造。
