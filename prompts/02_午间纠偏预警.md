## 步骤 1：读取今日盘前预案与策略状态（闭环入口，最优先 · JSON 优先）
按以下**三级优先级**读取基准（优先结构化 JSON，废弃脆弱的 Markdown 文本解析）：
1. **首选 `data/pre_market_state_YYYYMMDD.json`**（由盘前战略预案任务写入）：直接 `json.load` 读取，提取 positions[] 中每只标的的：action（建议动作）、order_price（竞价介入参考价）、stop_loss（止损位）、support（支撑位）、resistance（压力位）、trigger_condition、signal、news_check。这是最稳定、最权威的基准来源。
2. **回退 `data/strategy_state_YYYYMMDD.json`**（最近一个交易日，由盘后任务写入）：若 pre_market_state 不存在，用其中的 triggered_tickers 与 support_levels / resistance_levels / stop_loss 作为基准。
3. **再回退 盘前战略预案-YYYYMMDD.md**（今日日期）：仅当上述两个 JSON 均缺失时，才解析 MD「开盘竞价方案」表格提取建议动作、竞价介入参考价、止损位、支撑位、压力位。
4. 三者都不存在 → 明确标注「无预案基准，本次仅做常规盘中快照，破位预警章节标注不可用」，继续后续步骤，不要中断。
把提取到的「标的 → 支撑位 / 压力位 / 止损位」整理成一张内部基准表，后续所有比对以此为准。

## 步骤 5：破位判定（本任务核心逻辑）
对基准表中每只 A 级标的，用现价与基准价位比对，判定为以下之一并给出量化偏离度（(现价-基准位)/基准位，保留两位小数百分比）：
- 🚨 **已破止损**：现价 < 止损位 → 最高优先级，必须在报告最顶部单独列出
- ⚠️ **跌破支撑**：止损位 ≤ 现价 < 支撑位 → 预警，需说明是否放量下跌。判定「危险放量下跌」须**量价双因子交叉确认**：① 量比 > 1.5 **且** ② 换手率 ≥ 3%（个股）/ ≥ 1.5%（ETF）**且** ③ 主力净流出 → 危险；若仅量比 >1.5 但换手率未达标（如早盘 15 分钟脉冲放量、随后缩量），视为常规放量/正常轮动，降级为「观察」，避免午间量比欺骗性误报。
- 🟡 **支撑上方震荡**：支撑位 ≤ 现价 < 压力位 → 预案继续有效
- 🔴 **突破压力**：现价 ≥ 压力位 → 说明是否放量突破，给出下一目标位与移动止损建议（可将止损上移至原压力位）
判定时同时结合三项辅助证据：① 现价相对 VWAP（均价）位置，跌破均价是走弱确认；② 主力资金净流入方向；③ 所属板块是否同步走弱（板块普跌 → 个股破位可信度降低，属系统性回撤）。
