本任务是策略闭环的**第三环**（盘后写状态 → 盘前定预案 → 午间做监控纠偏 → 次日盘后复盘）。运行时点在午间休市（11:30-13:00）期间，核心目标不是复述上午行情，而是**校验盘前预案是否仍然成立，并对破位标的发出明确预警**。

## 步骤 0：交易状态前置检查（两道闸门，必须先做）
**闸门一（周末速退）**：运行 `date +%u`。若输出为 6 或 7（周六/周日），**立即输出一行「周末休市，跳过」并结束**，不得调用任何行情接口、爬虫或 MCP。调度器不支持 rrule 的 BYDAY 过滤，周末必然误触发，本闸门是唯一拦截手段。
**闸门二（节假日检查）**：工作日才执行——用腾讯自选股 data_quote 查 sh000001（上证指数）。若返回为空或最新日期非今日 → 判定为法定节假日/临时休市，仅输出一行休市通知并立即结束。

## 步骤 1：读取今日盘前预案与策略状态（闭环入口，最优先）
1. 读取 盘前战略预案-YYYYMMDD.md（今日日期）。提取「开盘执行预案」表格中每只 A 级标的的：建议动作、挂单价位、止损位、支撑位、压力位。
2. 若盘前文件不存在，回退读取 data/ 下最近一个 strategy_state_YYYYMMDD.json，用其中的 triggered_tickers 与 support_levels / resistance_levels / stop_loss 作为基准。

把提取到的「标的 → 支撑位 / 压力位 / 止损位」整理成一张内部基准表，后续所有比对以此为准。

## 步骤 5：破位判定（本任务核心逻辑）
对基准表中每只 A 级标的，用现价与基准价位比对，判定为以下之一并给出量化偏离度（(现价-基准位)/基准位，保留两位小数百分比）：
- 🚨 **已破止损**：现价 < 止损位 → 最高优先级，必须在报告最顶部单独列出
- ⚠️ **跌破支撑**：止损位 ≤ 现价 < 支撑位 → 预警，需说明是否放量下跌（量比 >1.5 且主力净流出 → 危险；缩量回踩 → 观察）
- 🟡 **支撑上方震荡**：支撑位 ≤ 现价 < 压力位 → 预案继续有效
- 🔴 **突破压力**：现价 ≥ 压力位 → 说明是否放量突破，给出下一目标位与移动止损建议（可将止损上移至原压力位）
判定时同时结合三项辅助证据：① 现价相对 VWAP（均价）位置，跌破均价是走弱确认；② 主力资金净流入方向；③ 所属板块是否同步走弱（板块普跌 → 个股破位可信度降低，属系统性回撤）。

## 步骤 6：交叉验证
抽取 2~3 只标的（**优先选已触发预警的 A 级标的**），用 腾讯自选股 与 通达信 两源比对现价（容差 0.5%）。
**破位预警必须双源确认后才能发出**——单源显示破位而另一源未破，需标注「单源信号，待确认」，不要直接报警。
ETF 折溢价率同时对比爬虫 skill（东财口径）与 data_quote 现价推算。报告开头写明验证结论。

### 操作建议标记规则（红绿锁 · 全局统一，必读）
为强化操作引导清晰度，本报告在**操作建议/建议动作**位置使用红绿锁标识，与涨跌颜色（🔴涨/🟢跌）**严格区分**：锁表示「操作方向」，涨跌表示「价格表现」，二者相互独立。
- 🔒红（建议买入 / 开放操作）：模型判定该标的当前应建仓、加仓或挂单介入
- 🔒绿（建议卖出 / 受限退出）：模型判定该标的当前应平仓、减仓、止损或放弃信号
标记写法一律用「🔒买入」/「🔒卖出」（锁图标+文字），**禁止使用 HTML `<span>` 颜色标签**。

报告结构（**破位预警必须置顶**）：

### 一、破位预警（核心，无预警也要明确写「本时段无破位标的」）
| 标的 | 现价 | 基准支撑 | 止损位 | 偏离度 | 状态 | 量能佐证 | 建议动作 |
- 状态用步骤 5 的四类标签

- **红绿锁标记**：建议动作=加仓突破跟进（突破压力且放量）→ 🔒买入；建议动作=立即止损离场 / 减仓一半观察（已破止损/跌破支撑）→ 🔒卖出；持有等待回补 / 维持原挂单为中性，不加锁。顶部🚨已破止损段统一标 🔒卖出

### 二、预案执行校验

- **红绿锁标记**：标注「已失效」的原盘前预案项 → 标 🔒卖出（意味着该预案建议已不成立，应退出或转观望）
